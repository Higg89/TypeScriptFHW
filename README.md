# Budget Tracker CLI

Интерактивное CLI-приложение для управления личными финансами (счета и транзакции) на TypeScript с использованием `inquirer`.

## Возможности

- Создание и удаление счетов.
- Просмотр сводки по счёту (баланс, доходы, расходы).
- Просмотр списка транзакций.
- Добавление и удаление транзакций.
- Экспорт транзакций выбранного счёта в CSV-файл.

## Запуск программы

Откройте обычную командную строку (cmd.exe):
Win+R → введите cmd → Enter.

Перейдите в папку проекта:
```bash
   cd /d (дирректория установки)\TypeScriptFHW
```
Запустите команды:
```bash
   npm run build   
   npm start
```

После запуска вы увидите главное меню со списком счетов и действиями:

- выбор счёта для работы;
- создание нового счёта;
- выход из приложения.

## Структура проекта

- `src/classes/`
  - `Account` — счёт, хранит транзакции и считает баланс.
  - `Transaction` — отдельная транзакция (доход/расход).
  - `AccountManager` — менеджер счетов.
  - `ApplicationController` — основной контроллер CLI (меню, операции).
- `src/interfaces/` — интерфейсы
- `src/utils/` — утилиты
- `src/lib/` — вспомогательные JS/типовые файлы.
- `src/index.ts` — точка входа приложения и начальное заполнение счетов.
